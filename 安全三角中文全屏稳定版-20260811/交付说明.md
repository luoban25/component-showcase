# 安全三角中文全屏稳定版｜交付说明

## 项目信息

- 项目名称：安全三角中文全屏稳定版
- 交付日期：2026-08-11
- 项目属性：未开源，仅供内部使用与留档
- 技术栈：Vue 3、TypeScript、Vite、SVG

## 当前版本

- 使用纯白全屏画布，画布始终覆盖浏览器视口。
- 三级菜单已完整中文化，并使用系统字体“苹方-简（PingFang SC）”。
- 菜单组在普通屏幕、超宽屏和紧凑窗口中保持整体居中。
- 安全三角使用绿色表示已确认路径、蓝色表示当前追踪路径。
- 子菜单由悬停驱动，斜向移动时保护用户通往下一层菜单的路径。
- 已修复菜单展开数量变化引起的整体位移和选项闪烁问题。

## 运行方式

首次运行需要安装依赖：

```bash
pnpm install
```

开发运行：

```bash
pnpm dev
```

Windows 用户安装依赖后，也可以双击 `打开网页.bat`。

## 生产构建

```bash
pnpm build
```

构建结果位于 `dist` 目录。交付包已经包含本次验证通过的最新生产构建。

## 目录说明

- `src`：完整项目源码。
- `dist`：可部署的生产构建产物。
- `package.json`：依赖与运行命令。
- `pnpm-lock.yaml`：锁定依赖版本，保证可重复安装。
- `README.md`：开发说明。
- `打开网页.bat`：Windows 本地启动入口。

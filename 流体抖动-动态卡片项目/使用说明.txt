流体抖动 · 动态卡片项目
========================

【版本备注】
更新日期：2026-08-28
主文件：流体抖动-动态卡片.html（单文件，自包含，双击即可运行）
页面形态：手机端使用 100vw × 100dvh；桌面端居中显示 390 × 844 手机成品预览。
UI 风格：纯黑背景、中性灰烟雾与轻量悬浮登录界面；烟雾位于全屏背景层，表单采用顶部品牌、左对齐标题和纵向登录流程。

【功能列表】
1. 烟雾模式
   - 拥有独立的种子、纹理、动态驱动、显形方式、流速、尺度、强度等参数；
   - 弯曲与卷度可独立调节，默认构图具有更明显的 S 型走势和旋卷感；
   - 默认使用无杂色的中性灰三色渐变，浅色 / 主色 / 深色仍可通过取色器实时调节。
2. 层次与流光
   - 层次纹理：双层 FBM，跟随流体流动；
   - 流光：两条斜向移动的柔光带；
   - 纵深感：中心略亮、上下边缘略暗。
3. 动效控制
   - 动效开关（开 / 关）；
   - 烟雾主体锚定在视口内，不再整块随机平移；
   - 内部流场持续驱动局部卷曲、拉伸、扩散、消散与重新聚合，形成更接近真实烟雾的运动；
   - 噪声相位缓慢上升形成浮力感，并保持不同手机尺寸下的构图稳定；
   - 动效强度（0.5–4，默认 1.0）与烟雾“流速”滑块均真实接入渲染。
4. 克制的边缘颗粒
   - 8×8 / 4×4 / 2×2 矩阵可切换；
   - 颗粒尺寸、密度增益、阈值偏移可调；
   - 保留原烟雾尺寸，并在上半区新增一块独立的参考图式半调云团；
   - 两块云团之间保留亮色间隔，Bayer 网格不随流体扭曲。
   - 点阵强度会根据烟雾密度与局部明暗自适应，黑底下的主烟雾区域仍保持可见抖动。
5. 随机生成
   - “生成”按钮随机烟雾参数；
   - 锁定芯片：纹理 / 动态 / 显形，可分别锁住对应参数。
6. 合成控制
   - 底色、前景浓度可调。

【操作方式】
- 登录区域：显示“欢迎回来”与“登录以管理您的 GPU 实例”，提供邮箱或账号、密码与忘记密码入口；
- 账号、密码、忘记密码和主登录按钮作为操作组在标题与底部第三方登录之间居中分布；
- 输入框使用统一的 1.6px 轻量细线矢量图标，并提供密码显隐按钮；忘记密码独立右对齐；
- 登录采用无彩色边框、无箭头的纯白胶囊按钮；“还没有账号？立即注册”使用底部轻量文字入口；
- Google、Telegram、GitHub 圆形玻璃图标按钮固定在纵向登录流程底部，使用低填充、低模糊的透明材质显示后方烟雾；
- 登录内容不使用整块卡片或局部背景框，烟雾直接作为完整页面背景；
- 输入框使用明确标签、自动填充语义、键盘焦点状态和必填校验，便于手机端与辅助技术使用；
- 手机键盘弹出或可视高度较小时，表单区域可纵向滚动，并自动隐藏会遮挡内容的效果设置入口；
- 页面顶部安全区居中显示代码绘制的 NodaCore SVG Logo 与品牌名称，不使用外框或胶囊背景，仅保留轻微投影保证烟雾上的可读性；
- 登录界面文字加载项目内的 PingFangSC-Regular.otf；当前按钮均为前端演示组件，正式接入时可绑定账号认证、OAuth 与 Telegram Login 流程；
- 桌面与手机端的“效果定稿”参数面板默认收纳；点击“效果设置”展开，点击面板右上角关闭按钮再次收纳；
- 可切换 8×8 / 4×4 抖动矩阵，调整烟雾浅色、主色、深色、颗粒尺寸与密度；
- “保存参数”：写入浏览器本地存储，刷新页面后自动恢复；
- “确定最终效果”：保存当前参数并标记为最终定稿状态；
- 调试参数：在地址后添加 ?debug=1 显示左下角“参数”按钮；
- “重置”：恢复全部默认参数；
- “生成”：随机抽取烟雾流体参数；
- 烟雾取色器：直接点击色块选色，实时生效。

【文件结构】
- 流体抖动-动态卡片.html：主程序（可独立运行）
- DAVYS.ttf：内置字体文件（备用）
- PingFangSC-Regular.otf：登录界面苹方字体
- NodaCore-logo-source.png：NodaCore 原始 Logo 资源
- 使用说明.txt：本文件

【技术栈】
- WebGL2 + GLSL Fragment Shader，单 Canvas、单 Pass；
- 程序化噪声（Value Noise + FBM）生成流体场；
- 连续灰阶主体 + 低强度 Bayer 边缘颗粒；
- 无任何外部图片 / 视频素材，画面全部实时计算。

【浏览器要求】
- 推荐 Chrome / Edge 最新版；
- 需要 WebGL2 支持。
- 使用 viewport-fit=cover、100vw、100dvh 与 safe-area-inset 适配异形屏；
- 已验证 360×800、375×812、390×844、393×873、430×932 及 844×390 横屏；桌面端按窗口等比缩放手机预览。

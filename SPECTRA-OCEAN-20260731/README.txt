SPECTRA OCEAN

这是网站中 OCEAN 蓝紫青配色的独立动态卡片（3:4 直角矩形），
页面右侧带组件控制面板，可实时调节文案、尺寸、圆角、
流动速度、强度、流体尺度、鼠标交互与配色。

打开方法：
1. 双击“启动预览.bat”。
2. 浏览器会自动打开动态作品。
3. 预览完成后，可关闭标题为 SPECTRA OCEAN SERVER 的窗口。

文件说明：
- index.html：作品入口
- assets/：运行所需样式与 WebGL 程序

注意：
- 请保留 index.html 与 assets 文件夹的相对位置。
- 作品需要通过本地服务器运行，不建议直接双击 index.html。

SPECTRA SMOKE CARD — ORIGINAL

这是从 AI CREATIVE LAB 首页独立整理出的第一个烟雾卡片工程包。

内容
- index.html：独立入口
- assets/index-wUQ1cSSQ.js：SPECTRA ORIGINAL 入口逻辑
- assets/index-C0fSA6dq.js：原始 React / Three.js / WebGL / GLSL 运行代码
- assets/index-BU_xtf1w.css：原始样式
- start-preview.bat：Windows 一键本地预览

使用方法
1. 双击 start-preview.bat。
2. 浏览器访问 http://127.0.0.1:43191/index.html。
3. 关闭命令窗口即可停止本地预览。

部署方法
将整个文件夹原样上传到任意静态网站空间即可。不要只上传 index.html，assets 文件夹是必需的。

说明
- 只保留 SPECTRA / ORIGINAL 一个效果。
- 未包含其他五个配色版本。
- 原始 WebGL、GLSL、速度、颜色、动画和交互参数均未修改。
- 这是已打包的静态工程，不需要 npm install 或重新构建。

## 页面特点

- **每张卡片都是「活」的** —— iframe 等比缩放原文件，动画实时运行，不是截图
- **4 列密集网格** —— 一屏可见 8 件，13 件两屏看完；顶部按分类即时筛选
- **悬停反馈** —— 缩略图浮起 + 「打开 ↗」+ 一句话说明从底部浮出
- **视口懒挂载**（IntersectionObserver）—— 只有进入视口的缩略图才挂 iframe，避免多个 WebGL 组件同屏撞浏览器上下文上限（约 16 个）
- **排版语言** —— 纯白底 / 墨黑字 / 1px 发丝线（阴影当边框）/ 等宽小标签 / 标题负字距
- **零外部 CDN** —— Spline 运行时已本地化到 `HTML组件-20260917/vendor/`，断网也能跑

## 本地预览

必须从**本目录**起本地服务：缩略图用相对路径 `./xxx` 引用同目录作品，直接双击 `index.html`（file://）会因跨域/资源限制而空白。

```bash
cd 作品集-github
py -m http.server 43210 --bind 127.0.0.1
# → http://127.0.0.1:43210/index.html
```

# 组件作品集

16 件可交互 UI 组件，按视觉风格归纳为 4 类：

- **01 玻璃拟态** — 天气卡、登录页、SPECTRA 卡片、PULSE 光圈
- **02 状态指示** — 状态胶囊、Smooth 状态流转、Fluid 进度条
- **03 流体动效** — AI 对话、滑动烟雾、丝带、背景折射、抖动数据
- **04 3D · 复刻** — Spline 脸、安全三角、ShipSwift 复刻

每张卡片都是「活」的：iframe 等比缩放原文件，动画实时运行；点卡片弹出浮动窗口可完整交互。

## 本地运行

需要从本目录起本地服务（缩略图用相对路径引用同目录作品，file:// 直接打开会因跨域/资源限制空白）：

```bash
cd 作品集-github
py -m http.server 43210 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:43210/index.html
```

## 技术

纯浏览器端、零框架零构建：CSS 网格 + iframe 等比缩放 + IntersectionObserver 视口懒挂载 + 3D 卡片倾斜。作品本体含 WebGL / Canvas / Three.js / Spline 等，均为自包含或带本地资源。
